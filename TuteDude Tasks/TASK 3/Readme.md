# HTML & CSS Styling Task

## Description

This is a simple HTML and CSS practice task. I used different CSS selectors to style headings, paragraphs, links, and list items.

## Concepts Used

* Element selectors
* Class selectors
* ID selectors
* Child selectors (`>`)
* `nth-child()` selector
* Background and text colors
* Styling elements inside other elements

## How to Run

1. Keep the `HTML` and `style.css` files in the same folder.
2. Open the HTML file in a web browser.
3. The styled webpage will be displayed.
