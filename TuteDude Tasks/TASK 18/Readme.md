# JavaScript DOM Practice

A small JavaScript project to practice basic **DOM manipulation and event handling**.

### Features

* Change the background color of boxes by clicking them.
* Read the value entered in the input field.
* Update the heading with the entered name.
* Prevent the form from refreshing the page.

### Technologies

* HTML
* CSS
* JavaScript

### How to Run

Open the `index.html` file in a browser and try clicking the color boxes or submitting a name.
