# Shoe E-Commerce Website

A simple frontend e-commerce website for browsing and purchasing shoes. The project is built using HTML and CSS with basic JavaScript navigation.

## Features

* Home page with product promotion
* Product details page
* Shopping cart
* Checkout page
* Payment method selection
* Coupon code section
* Order summary
* Basic form inputs and styling

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

## Project Flow

Home → Product Details → Cart → Checkout

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Purpose

This project was created to practice frontend development concepts such as HTML forms, Flexbox, CSS Grid, navigation, and basic JavaScript.
