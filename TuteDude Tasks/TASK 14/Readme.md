# JavaScript Number Programs

This project contains basic JavaScript programs to perform common number operations using `for` loops and `while` loops.

## Programs Included

* Sum of first N numbers
* Print numbers from 0 to N
* Check whether a number is prime
* Find factors of a number
* Find the sum of digits
* Check whether a number is an Armstrong number

## Technologies Used

* JavaScript

## How to Run

1. Save the code in a file, for example:
   `index.js`
2. Run it using Node.js:

```bash
node index.js
```

## Example

For `num = 153`, the program calculates the sum of numbers, prints numbers from 0 to 153, checks for prime status, finds factors, calculates the digit sum, and checks whether 153 is an Armstrong number.
