# Image and Gradient Button

## About the Project

This is a simple HTML and CSS project where I created a webpage that displays an image with a button below it.

The button has a gradient background that changes from yellow/orange to green.

## Technologies Used

* HTML
* CSS

## What I Used

* Added an image using HTML.
* Used CSS to set the image size.
* Centered the content on the page.
* Added a button below the image.
* Used `linear-gradient()` to give the button a gradient color.

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. The webpage will be displayed.
