# Laundry Service Booking

This is a simple laundry service booking website made using HTML, CSS, and JavaScript. Users can check the available laundry services, add the services they need to the cart, and book them by entering their details.

## Features

* View different laundry services
* Add services to the cart
* Skip services that are not needed
* Automatically calculate the total price
* Book a laundry service
* Enter name, email, and phone number
* Basic form validation

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the project.
2. Open the `index.html` file in a browser.
3. Check the available laundry services.
4. Add the services you want to the cart.
5. Enter your details and click **Book Now**.

## Project Structure

* `index.html` – Main page of the website
* `style.css` – Styles and design of the website
* `script.js` – Handles the website functionality
* `images/` – Contains the images used for the services
