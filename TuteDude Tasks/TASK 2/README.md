# Laundry Wallah HTML

## Description

This is a basic HTML project for a laundry service website.

The webpage provides information about Laundry Wallah, including the services offered, price list, booking form, and contact details.

## Technologies Used

* HTML5

## Features

* About Us section
* Laundry services list
* Price list
* Booking form
* Contact information
* Laundry image

## How to Run

1. Open the `index.html` file.
2. It will open in a web browser.
3. The Laundry Wallah webpage will be displayed.
