# Login Page

## About the Project

This is a simple HTML and CSS project where I created a basic login page.

It includes an image on the left side and a login form on the right side with email, password, forgot password, login button, and registration link.

## Technologies Used

* HTML
* CSS

## What I Used

* Created the login page structure using HTML.
* Added an image using `<img>`.
* Created a login form using HTML form elements.
* Added email and password input boxes.
* Added a "Forgot Password" link.
* Added a login button and registration link.
* Used CSS Flexbox to divide the page into two sections.
* Centered the image and login form using `justify-content` and `align-items`.
* Styled the input boxes with rounded corners and borders.
* Added focus effects to the input fields.
* Styled the login button with a background color and hover effect.
* Used `margin`, `padding`, `width`, and `height` for spacing and layout.

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. The login page will be displayed.
