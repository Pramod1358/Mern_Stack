# Laundry Service Webpage

## About the Project

This is a simple HTML and CSS project where I created a basic laundry service webpage.

It includes a navigation bar with a logo and links, a laundry-related image, some text about the service, and a button to book a service.

## Technologies Used

* HTML
* CSS

## What I Used

* Created a navigation bar using HTML.
* Added images using `<img>`.
* Added navigation links using anchor tags.
* Used CSS to position the images and content.
* Styled the heading, paragraph, and button.
* Used `float`, `position`, `margin`, and `padding` for layout.
* Added rounded corners and background color to the button.

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. The laundry service webpage will be displayed.
