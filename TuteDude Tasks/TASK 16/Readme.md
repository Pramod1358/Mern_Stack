# Player Search

A simple JavaScript project that displays a list of players with their ID and score.

## Features

- Displays player details dynamically using JavaScript.
- Search players by name.
- Search is case-insensitive.
- Shows matching players instantly after clicking the Search button.

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The player data is stored in a JavaScript array of objects.  
JavaScript uses `map()` to display the players and `filter()` to find players whose names match the search input.

## Run

Open `index.html` in your browser and search for any player's name.
