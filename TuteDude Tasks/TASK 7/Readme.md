# Laundry Service Webpage

## About the Project

This is a simple HTML and CSS project where I created a basic laundry service webpage.

It includes a navigation bar with a logo, navigation links, and a user image. The webpage also has a laundry service heading, description, booking button, and a laundry-related image.

## Technologies Used

* HTML
* CSS

## What I Used

* Created the webpage structure using HTML.
* Created a navigation bar using HTML and CSS.
* Added images using `<img>`.
* Added navigation links using `<a>`.
* Used CSS Flexbox to arrange the navigation bar and webpage sections.
* Used `justify-content` and `align-items` for positioning.
* Styled the booking button with a background color, rounded corners, and hover effect.
* Used `margin`, `padding`, `width`, and `height` for spacing and layout.
* Used a media query to make the webpage responsive.
* Hid the navigation links when the screen width is less than 1000px.
* Changed the section layout to a column on smaller screens.
* Used `font-family` to style the heading and paragraph.

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. The laundry service webpage will be displayed.
