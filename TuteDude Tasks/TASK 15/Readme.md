# JavaScript Array Programs

A simple JavaScript practice program where I worked with an array and performed some basic operations using loops and conditions.

## What it does

* Finds the **largest number** in the array
* Calculates the **sum of all elements**
* Counts the **number of odd elements**

## Concepts Used

* Arrays
* `for` loops
* `if` conditions
* Modulus operator `%`
* Variables and counters

## How to Run

Run the JavaScript file using Node.js:

```bash
node script.js
```

The results will be printed in the console.
